# MeshJoy

*Read this in [🇬🇧 English](README.md).*

![Плата MeshJoy](docs/images/meshjoy-board.png)

Портативний пристрій для радіомережі **Meshtastic / Meshcore** з максимальною потужністю **1 Вт LoRa** і часом роботи **3–4 доби**.

Для туристів, радіоаматорів та тих, кому потрібен зв'язок без інтернету.

> Статус: v0.2.2 зібрано і протестовано.

## Особливості

- **Джойстик + OLED екран** — зручна навігація по меню 4-позиційним джойстиком з натисненням.
- **Фізична кнопка вимкнення** — механічно-електронне керування живленням.
- **Вимикач GPS** — GPS можна вимкнути програмно *або* апаратним вимикачем на корпусі.
- **GPS навігація** (за бажанням) — приймач Ebyte E108-GN02D визначає координати із заданими інтервалами та передає їх у публічну мережу Meshtastic або лише вибраним контактам. Між інтервалами приймач вимикається для економії батареї.
- **Звуковий сповіщувач** — вже встановлений на платі.
- **Розширюваність** — опційний вібродвигун; доступ до кнопки reset і видимість світлодіодів без розбирання корпусу.
- **Вбудований зарядний пристрій** — заряджанням керує мікроконтролер; захист від розряду через BMS батареї.

## Технічні деталі

- **Процесор:** nRF52840 (клон ProMicro / SuperMini) — енергоощадний, Bluetooth, без Wi-Fi. Вбудований контролер заряду LiPo і 2 світлодіоди. Кнопка reset виведена на головну плату.
- **LoRa:** Ebyte E22-400M30S, 1 Вт на 433 МГц. При 5 В впевнено видає 1–1,2 Вт.
- **Розʼєм антени:** SMA female, монтується паралельно поверхні плати — легше паяти і зручніше в малому корпусі.
- **Живлення:** Від батареї 1S (3,7 В) або USB-C. Перетворювач XL6380 забезпечує 5 В для LoRa. Піковий струм під час передавання до ~1,5 А; середнє споживання з тестовою передачею що 5 хв — ~65 мВт.
- **Вимкнення:** Комбіноване механічно-електричне — фізична кнопка керує MOSFET, який комутує струм батареї (звичайний мікровимикач не витримує пік ~1,5 А).
- **Джойстик:** 4 позиції + натиснення; паяється як SMD. Звідси й назва — "Mesh" + "joystick".
- **Екран:** Стандартний OLED 0,96" (розпіновка GND-VCC).
- **Керування зовнішніми пристроями:** 2 силові MOSFET комутують "мінус" — один для пискалки, інший виведено для вібродвигуна або керування GPS. Повзунковий вимикач також комутує +5 В для пристроїв з низьким споживанням (напр. повне вимкнення GPS).
- **Плата:** Розроблена спеціально, використовує стандартну розпіновку `nrf52_promicro_diy_tcxo` для Meshtastic.

## Корпус

![Корпус MeshJoy](docs/images/meshjoy-enclosure.png)

Корпус створений "з нуля" у Fusion 360 і буде **доступний для безкоштовного завантаження й модифікації**. Оптимізований для швидкого 3D-друку без підтримок (PETG). Рамка екрану заклацується у верхню кришку без клею; частини скріплюються гвинтами М2 (без гайок), плата фіксується вбудованими стійками. Передбачено кріплення для GPS-модуля.
